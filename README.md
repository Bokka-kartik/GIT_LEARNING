# Git Learning Project

This repository is a small learning project focused on Git, GitHub, and basic front-end development workflows.

## What this project contains

- A Vite + React app in the Git1 folder for practicing UI development and Git-based collaboration.
- Basic JavaScript utility functions for arithmetic operations such as add, subtract, divide, multiply, and modulus.
- A simple GraphQL-style demo that shows how schema, resolver, and client data can be organized in a front-end app.
- Husky Git hooks to enforce basic commit and pre-commit checks during development.

## Project structure

- Git1/ - Main React project
  - src/ - Application source code
  - public/ - Static assets
  - .husky/ - Git hooks for commit validation
- README.md - Overview of the repository

## Main goals

- Learn how Git branches, commits, and pushes work in practice.
- Practice creating and managing a small React app.
- Understand how hooks can help enforce coding and commit standards.
- Explore simple frontend concepts such as state, components, and utility modules.

## Getting started

1. Open the Git1 folder.
2. Install dependencies with npm install.
3. Start the development server with npm run dev.

## Notes

This project is intended as a learning and practice repository, so it is kept simple and beginner-friendly.
