## Status labels

- **To explore** — read about it and try a small, safe example.
- **In progress** — actively learning or building with it.
- **Tried** — completed a hands-on example; add a short takeaway to the note.
- **Revisit** — useful, but details or understanding need refreshing.
- **Documented** — covered by the existing repository documentation.
